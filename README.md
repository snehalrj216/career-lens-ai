# 🚀 CareerLens AI

CareerLens AI is an AI-powered career guidance platform designed to help users understand their career opportunities, analyze resumes, and generate personalized career roadmaps.

The application combines a modern React frontend with a Node.js/Express backend, MongoDB for data storage, and Google Gemini AI for intelligent career-related analysis.

---

## ✨ Features

- 👤 **User Profile Management**
  - Create and save user profiles
  - Store career-related information

- 🎯 **AI Career Analysis**
  - Analyze user skills, interests, and career information
  - Generate AI-powered career recommendations

- 📄 **Resume Analysis**
  - Upload and analyze resumes
  - Get AI-generated insights and suggestions

- 🗺️ **Personalized Career Roadmap**
  - Generate a structured roadmap based on the user's career goals
  - Identify relevant skills and learning areas

- 🤖 **Gemini AI Integration**
  - Uses Google Gemini AI for intelligent analysis and recommendations

- 💾 **MongoDB Database**
  - Stores user profiles and analysis-related data

- 🌐 **Full-Stack Deployment**
  - Frontend deployed on Vercel
  - Backend deployed on Render
